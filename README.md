# House Price Prediction

## Project Overview

This project predicts house prices using Machine Learning with Python.

## Technologies Used

* Python
* Pandas
* Scikit-learn

## Dataset

The dataset contains house details such as:

* Area
* Bedrooms
* Bathrooms
* Age
* Price

## Machine Learning Algorithm

Linear Regression

## How to Run

1. Install the required libraries:
   `py -m pip install pandas scikit-learn`
2. Keep `House_Price.csv` and the Python file in the same folder.
3. Run:
   `py House_Price_Prediction.py`

## Note

This is a beginner practice project using sample data. Predictions are not intended for real estate decisions.
